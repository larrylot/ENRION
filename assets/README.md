# ENRION visual identity

`enrion-logo.png` is the original ENRION brand image from October 2026, preserved
without alteration. It includes the emblem, wordmark, tagline and app icon concept.

`enrion-logo-dark.png` is the simplified dark identity created in November 2026.
It replaces the original in the repository README and keeps a geometric emblem,
wordmark and restrained blue accent without the mascot, tagline or app icon example.
The original file remains available for reference.

Both files are raster PNGs, not vector masters or transparent cutouts. The dark
version was created with AI image generation from the original, using the brief:
clean minimal dark logo, exact ENRION wordmark, simpler protective geometric emblem,
no mascot, no slogan, no orbital decoration.
