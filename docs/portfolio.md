# Portfolio summary

## English

ENRION is my independent learning project exploring autonomous agent security and
AI governance through practical Python labs. The current prototype compares a
vulnerable file agent with an externally enforced authorization gateway, including
scoped permissions, decision telemetry, a stop control and regression tests.
Threat modeling and a staged roadmap describe the boundaries still to be tested.

## Svenska

ENRION är mitt eget lärandeprojekt inom agentsäkerhet och AI governance. Jag bygger
praktiska Pythonlabbar för att undersöka behörigheter, styrning och spårbarhet när
en agent fattar fel beslut. Projektet innehåller en sårbar och en försvarad
filagent, automatiserade tester samt en hotmodell och plan för fortsatt utveckling.

## Scope and attribution

This is a personal learning and architecture project, not a customer delivery or
production platform. AI assistance is used in development and review. Repository
tests and evidence records describe observed behavior, not independent certification
or proof of the maintainer's mastery of every topic in the curriculum.
